Privacy Policy

Effective 8 November 2026 · Applies to the YouTube channel 「曉晴・AI 數據解碼」, this website, and the app Sunny Video Uploader.

簡要（中文）

「Sunny Video Uploader」只由本頻道擁有人使用，經 YouTube API 服務上載和管理本頻道自己的影片。它不會收集觀眾或其他用戶的資料，也不會出售或分享任何資料。本網站不使用 cookies 或追蹤工具。使用本工具即受 YouTube 服務條款及 Google 私隱權政策約束。

1. Who we are

「曉晴・AI 數據解碼」 is a YouTube channel about the US stock market, presented by an AI-generated anchor. Sunny Video Uploader is the channel's own internal tool. It is not offered to the public and is used only by the channel owner.

2. YouTube API Services

Sunny Video Uploader uses the YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. What the app accesses and why

With the channel owner's permission (Google OAuth), the app accesses only the owner's own YouTube channel, to:

  • upload the channel's videos, and set their title, description, tags, thumbnail, captions and playlist;
  • read the channel's basic information and its own video list, to confirm uploads succeeded.

It does not read, collect or store data about viewers or any other YouTube user, and it does not use the data for advertising.

4. How the data is stored

The access token Google issues is kept on a private server, readable only by the channel owner's account, and is never shared. Videos, titles and descriptions are the channel's own content.

5. Sharing

We do not sell, rent or share any data. Information is sent only to Google/YouTube, as needed to upload and manage the channel's videos.

6. Revoking access and deletion

The app's access can be removed at any time from the Google security settings page: myaccount.google.com/permissions (Third-party apps & services → Sunny Video Uploader → Delete all connections). Stored tokens are deleted when access is revoked or the app is retired, and on request.

7. This website

This site is a static page. It uses no cookies, analytics or tracking. It is hosted on GitHub Pages; GitHub may log visitors' IP addresses for security, as described in the GitHub Privacy Statement.

8. Changes

If this policy changes, the new version will be posted on this page with a new effective date.
